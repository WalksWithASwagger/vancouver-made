## 0. How to use this

The official Formme template (`Vancouver-Made_Formme_Tech-Pack.pdf`) is deliberately
beginner-friendly — its Materials pages literally say *"no technical terms needed."* That's
the **floor**. We answer it in two registers:

| Register | Goes where | Voice |
|---|---|---|
| **Template fill** | Official template Materials 01/02 + Colour Story pages | Plain language ("smooth recycled performance knit", "soft mesh collar"). See [§3.8](#38-template-fill). |
| **Pro BOM + size chart** | Flexible-space pages of the template **and** the standalone MADE ON tech pack | Manufacturer spec — fabric/gsm/cert, POM grids, finishes, labels. This whole doc. |

Doing both is the differentiator: it satisfies the judged template **and** proves the kit is
actually manufacturable. The pro spec is what lets Formme make the 10 prize kits without a
single guess.

**Scope note:** §1–§3 (construction, sizing, materials) are **collection-level** — all 9 MADE
ON kits share one block and one base fabrication; only surface decoration changes kit to kit.
§5 covers the per-kit craft flexes. Spec once, reuse nine times.

## 2. Sizing & fit

### 2.1 Fit decision

Football kit comes in two cuts (plus a looser "fan" tier):

| Industry name(s) | Cut | Built for |
|---|---|---|
| **Authentic / Player / Match / Vapor** | Slim, athletic, body-hugging; engineered stretch panels | On-pitch players, collectors |
| **Replica / Stadium / Regular** | Relaxed, forgiving, "everyday shirt" feel | Fans, mixed body types |
| Fan / Supporter | Loosest, T-shirt-like | Casual wear |

> **✅ Spec the REPLICA / STADIUM / REGULAR fit (relaxed match-fit).** A designathon kit is worn
> by varied, unknown bodies across XS–3XL — not a roster of athletes. The slim authentic cut
> forces a per-person "size up" decision and looks wrong on non-athletic frames; the relaxed
> block fits the widest range with the fewest fails and is more forgiving of sewing/grading
> tolerance on a short ~10-unit run. Keep it **trim, not boxy** — a "tailored regular." Standard
> fitting rule to print on the chart: *if between sizes, go by chest and size up.*
> (Note: "regular" is brand-relative — Castore/Kappa/Umbro Euro-cut run closer to slim.)

### 2.6 Grading & tolerances

**Grade increments per size step** (confirmed against the published charts — e.g. ApparelnBags
jersey grades exactly +2″ chest-width/size = +4″ full circumference):

| Measure | Grade per size (full) |
|---|---|
| Chest circumference | **+4″ / +10 cm** |
| Body length (jersey) | **+1″ / +2.5 cm** |
| Across shoulder | +¾–1″ / +2–2.5 cm `[c]` |
| Sleeve length | **+¼″ / +0.6 cm** |
| Shorts waist (circ.) | **+2″ / +5 cm** (S–L), widening to +3″ at XL+ |
| Hip / seat | +1½–2″ / +4–5 cm `[c]` |
| Inseam | 0″ (S–L), +¼″ XL+ |

*Real charts widen the grade at the top end (waist +2″→+3″); Augusta confirms consistent +4″
chest/waist/hip steps XS→6XL.*

**Tolerances** (acceptable ± production variance — large parts looser, small parts tighter):

| Part class | Examples | Imperial | Metric |
|---|---|---|---|
| Large body parts | chest, body length, hip, waist, hem, outseam | **±½″** | **±1.0–1.5 cm** |
| Medium parts | shoulder, sleeve, thigh, rise, leg opening | **±¼″** | **±0.6 cm** |
| Small parts | neck width, neck drop, waistband height | **±⅛″** | **±0.3 cm** |

> For a ~10-unit run the ±0.6–1.5 cm column is realistic and manufacturer-friendly. Tightening
> to premium ±0.5 cm raises reject rate/cost — only do it on fit-critical POMs (chest, waist,
> body length). **State tolerances on the pack so Formme isn't guessing.**

### 2.7 POM conventions (how the size page should read)

1. **POM codes** (A, B, C…) keyed to a flat sketch with the same labels — factory references the code.
2. **Spec one base size fully** (M or L), the rest as a graded spec. State the base size.
3. **Mark every circumference "(½) — measured flat ×2."** Lengths are full/direct.
4. **HPS = High Point Shoulder** is the anchor for body length + neck drop.
5. Give a one-line **how-to-measure** per POM (e.g. *Chest: 1″ below armhole, side to side*).
6. **Two waist rows** (relaxed + stretched) for the pull-on shorts — elastic can't be QC'd on one number.
7. Lead in one unit, other in parentheses (this pack: cm + in). **Tolerance column on every row.**
8. State conditions: garment flat, relaxed, seams flat, hard surface.

### 2.8 Women's / youth / inclusive options

| Variant | What changes |
|---|---|
| **Women's jersey** | ~3″/7.5 cm shorter body, narrower shoulder, slight waist shaping |
| **Women's shorts** | Much shorter inseam (~3¼″ vs 7″), higher waist, fuller hip-to-waist |

## 3. Materials / BOM

### 3.1 Body fabric (jersey)

All options are **100% polyester** (± elastane) — a hard requirement for dye-sublimation, which
only gas-bonds to synthetic fibre.

| Knit | Composition | Weight (gsm) | Sublimation suitability | Verdict |
|---|---|---|---|---|
| **Interlock** (smooth double-knit) | 100% poly (or 90/10 poly/elastane) | **140–170** | **Excellent** — smooth closed face = sharpest print, opaque, no show-through | **★ PRIMARY** |
| Piqué / bird's-eye | 100% poly | ~140–160 | Very good; slight texture softens finest lines | Alt 1 (drier hand, more breathable) |
| Micro-mesh | 100% poly | 120–160 | Holes break edge-to-edge fills | Vent panels only |
| Double-knit (heavy) | 100% poly | 160–280 | Good but warmer/heavier than needed | — |
| Jacquard | 100% poly | ~150–180 `[c]` | Raised texture distorts fine detail | Tonal interest only |

> **★ PRIMARY: 100% recycled-polyester interlock, ~150 gsm**, optical-bright base,
> sublimation-ready. Best balance of print sharpness, opacity under stadium light, durability
> for ~10 wearers, and the light soccer hand.
> **Alt 1:** 100% poly micro-piqué ~150 gsm (drier, more breathable; accept slightly softer fine detail).
> **Alt 2 (engineered knit-map):** interlock body + micro-mesh side/back vent panels (~140 gsm)
> for airflow — adds seams/cost, only if ventilation is a priority.

*Real suppliers to source from: Wooter, Ninghow, Rajco USA (100% recycled poly interlock), Soardist, Rex Fabrics.*

### 3.2 gsm verification

| Garment | Draft | Verified range | **Recommended** |
|---|---|---|---|
| Jersey body | ~150 gsm ✅ | 135–165 (sweet spot 140–160) | **~150 gsm interlock — keep** |
| Shorts | (none) | match shorts ~180 | **~180 gsm interlock** |

**`~150 gsm` is correct — do not lighten further** (sub-135 risks show-through + durability over
a 10-wearer life). Ignore 200–220 gsm figures seen online — those are baseball/general active
interlock, not soccer tops.

### 3.3 Shorts fabric

**100% recycled-poly interlock, ~180 gsm** — heavier than the jersey for abrasion (slide
tackles) + opacity when stretched over the thigh; still lightweight. 100% poly for cleanest
sublimation (add 90/10 poly/elastane only if a fitted short is wanted). Alt: lightweight woven
micro-poly for a crisper short — but confirm sublimation strike-off and recovery `[confirm]`.

### 3.4 Collar / cuff / trim / waistband

Self-fabric interlock won't control a neckline edge alone — neck/cuff need stretch + recovery.

| Option | Use | Note |
|---|---|---|
| **1×1 rib (poly/spandex)** | Crew/V binding, cuffs | Default for durability; rib is a solid colour (breaks the print at the edge) |
| **Self-fabric bound (folded interlock)** | Clean V/crew bind | **Lets the sublimated art run edge-to-edge into the collar** — on-brand for a sublimation-first kit; needs taping for recovery |
| 2×2 rib | Chunkier collar/cuff | Heavier than needed for a light top |
| Flat-knit / jacquard collar | Polo style, knit-in stripes/text | Premium; adds cost + separate trim sourcing |

**Shorts waistband:** elastic + internal drawcord (baseline) → upgrade to **custom jacquard
elastic band with the MADE ON wordmark** woven in (subtle anti-merch branding; confirm MOQ/lead).

> **MADE ON recommendation:** **self-fabric bound V-neck** so the graphic wraps the neckline
> uninterrupted (the art *is* the garment), with rib as the durable fallback if Formme prefers.

### 3.5 Recycled content + certifications (how to spec it)

**BOM line, written properly:**
> *Body: 100% recycled polyester (rPET), GRS-certified, [REPREVE® branded fiber], ~150 gsm
> interlock, OEKO-TEX STANDARD 100 certified, optical-bright sublimation-ready.*

| Cert | Body | Certifies | Threshold |
|---|---|---|---|
| **GRS** (Global Recycled Standard) | Textile Exchange | Recycled input + chain-of-custody + social/environmental + chemical | ≥20% (B2B); ≥50% for consumer labeling |
| **RCS** (Recycled Claim Standard) | Textile Exchange | Recycled content + chain-of-custody only | ≥5% |
| **OEKO-TEX STANDARD 100** | OEKO-TEX | Tested safe against 1,000+ harmful substances | — |
| **bluesign** | bluesign | Safer chemistry/resource use across supply chain | — |
| **REPREVE** (Unifi) | Unifi | Branded, *traceable* rPET (FiberPrint tracer); used in PFP/sublimation wear | — |

**Honest sustainability framing** (for the anti-merch ethos — say it plainly): dye-sublimation
is genuinely low-impact at the *dyeing* step (heat-transferred dye, **no dye-bath water, no
wastewater**). **But** the substrate is still fossil-derived plastic that sheds microplastics and
isn't biodegradable. Recycled fibre **mitigates** (diverts ~18 bottles/kit, ~59% less production
energy vs virgin) but doesn't eliminate it. → *"Lower-impact, not zero-impact: recycled fibre +
waterless dye, made in a small ~10-kit run to avoid overproduction."*

### 3.6 Performance finishes (what's worth speccing)

| Property | Spec? | Note |
|---|---|---|
| **Moisture-wicking** | **Yes** | Demand a **fibre-integrated** wicking finish (lasts 100+ washes), not a topical coating (washes out in 10–20) |
| Elastane % | Optional | Fit decision, not a performance necessity. **Default 0% (cleanest sublimation)**; add 5–15% only for a fitted cut |
| Anti-odor / antimicrobial | Skip-ish | Only real if fibre-embedded (silver-ion, ~100 washes); skip for a 10-kit art project unless free/standard |
| UPF | Skip | Tight ~150 gsm poly already blocks UV; separate UPF claim adds little |

## 4. Decoration & print methods

### 4.1 Method comparison

| Method | Best for | Min line / type | Durability | Cost / complexity |
|---|---|---|---|---|
| **Dye-sublimation** (all-over) | Edge-to-edge graphics, gradients, engraving looks; zero hand-feel | ~12 pt razor-sharp (finer w/ vector @ 300 DPI); no hard floor | Dye is *in* the fibre — won't crack/peel/fade; needs ≥65% poly | High art/RIP setup; cheap per-unit; free to add colour/coverage |
| **Screen print** | Bold spot-colour logos, solid fills | line 0.012″; 8 pt safe text; stroke ≥1 pt | Good; thick film can crack over many washes | Per-colour screen setup; cheap at volume; poor for photographic |
| **Heat transfer / DTF** | Full-colour names/numbers/small logos, short runs | line ~0.4–0.5 mm; +text ≥6 pt; reversed ≥9–10 pt | 50+ washes lab-tested w/ proper care; can edge-lift if mis-pressed | No setup, no MOQ; higher per-unit at volume |
| **Embroidery** | Crests, small chest logos, premium tactile | text ≥6.35 mm; min column 0.8–1.27 mm | Excellent; survives industrial wash | High digitizing; can pucker thin poly |
| **Woven patch** | Detailed crest w/ fine type | text 3–4 mm, line 1 mm (finer than embroidery) | Thin, smooth, durable | Patch tooling; low per-unit at volume |
| **Tackle twill / applique** | Large names/numbers/simple crests; pro raised look | large only — avoid fine detail | Among the most durable | Cut-and-sew labour; only worth it for large designs |
| **Silicone / 3D transfer** | Raised dimensional crest/logo; stretchy on poly | bold shapes; coarse for fine type | 50+ industrial washes; stretches/recovers | Mould/screen setup (high) |

### 4.2 Element → method mapping

| Kit element | Recommended | Why |
|---|---|---|
| **All-over graphic** | **Dye-sublimation** | Only method for edge-to-edge fine detail/gradients dyed into poly, zero hand |
| **Crest / badge** | Sublimated (flat, full detail) → upgrade to **woven patch / embroidery / silicone** for tactile premium | Sublimation reproduces fine detail flat; woven holds 3–4 mm type if raised |
| **Sponsor bar** | Sublimation (if fixed in base art); DTF/screen if variable | Free if it's in the file |
| **Name + number** | Sublimation (if pre-known); else DTF (full-colour) or tackle twill (pro raised) | Large → clears all size floors |
| **Hem micro-type** | **Dye-sublimation only** | Below every *applied* method's floor (DTF 6 pt, screen 8 pt, embroidery 6.35 mm) |

> **Net build:** bake everything possible into **one sublimation file** (all-over + crest + fixed
> sponsor + names/numbers + hem micro-type). Break out to applied methods only for *variable*
> elements (DTF) or *premium raised* ones (twill / silicone / embroidery).

## 5. Concept-specific finishes

The craft flexes that make each hero kit. Each pressure-tested for manufacturability with a
fallback.

### 5.1 Metallic gold — MO-03 "Public Dime" (banknote)

**Metallic dye-sublimation is not real** — sublimation dye is translucent and bonds *inside* the
fibre; it can't lay an opaque reflective metal layer.

| Approach | On poly? | How | Caveat |
|---|---|---|---|
| **★ Metallic HTV — Stahls CAD-CUT Metallic Gold** | Yes | 88-µ PU film, cut + heat-pressed (~15 s @ 320°F/160°C, hot peel `[confirm]`) | Sits on top (hand); fine engraving-line detail limited by cut/weed; lower temp + cover sheet on heat-sensitive poly |
| Heat-transfer foil | Yes | 2-step adhesive + foil | Brightest, **least durable** (~50 washes, cracks under stretch) — small crest only, not the flexing body |
| **★ Tonal old-gold via sublimation (fallback)** | Yes | Print warm ochre; line density sells the "engraving" | No shine, but engraving detail excellent |

**Recommendation:** true-metallic crest/sponsor → **Stahls CAD-CUT Metallic Gold**; foil for tiny
accents only. The body banknote-engraving → **sublimate in non-metallic old-gold** and let line
density carry it. Colour targets: Pantone **Old Gold 15-0955 TCX** (#ECA825, brighter) or
**Antique Gold 16-0730 TCX** (#B59E5F, muted) — build CMYK at print size against Formme's ICC profile `[confirm]`.

### 5.2 Matte body + gloss redaction bars — MO-01 "Made on Silence"

**Yes — a recognized tone-on-tone technique.** Sublimated poly reads matte; an applied **gloss
element on top** delivers the sheen contrast (the matte-on-matte look reads only in raking light).

| Method for gloss bars | How | Caveat |
|---|---|---|
| **★ 3D silicone / liquid-silicone transfer** | Glossy raised black bar over the matte sublimated ground | Confirm silicone bonds to the *sublimated* surface `[confirm]` |
| Gloss / clear DTF | Gloss-black or clear bar over matte | Wash-durability over sublimation `[confirm on swatch]` |
| Gloss / clear screen overprint | Tonal clear-gloss plastisol bars | Plastisol hand/crack — keep off high-stretch zones |

**Caveat:** all sit *on top* → raised hand + different stretch. **Keep bars on low-flex zones
(hem, lower back).** Tone-match the black exactly so only the sheen differs.

### 5.3 Micro-type hem citations (all kits)

**Yes — sublimation holds the smallest.** The "receipt" fine print is below every applied
method's floor.

| Method | Min legible text | Notes |
|---|---|---|
| **★ Dye-sublimation** | ~12 pt razor-sharp; finer w/ vector @ 300 DPI | No ink film to clog letterforms — best for dense fine print |
| HD / DTF | +text ≥6 pt; reversed ≥9–10 pt | Features <0.35–0.40 mm break on textured blanks/seams |
| Screen | ~6 pt floor, 8 pt safe | Thin strokes break; avoid for micro-type |

**Spec:** micro-type **vector**, **≥~6–8 pt** to survive a flexing hem, sans-serif, and **proof on
the real blank** — woven texture is the true limiter, not the printer.

### 5.4 Toxic-neon gradients — MO-09 "Pump and Dump"

**Partly** — standard CMYK sublimation can't hit *true* fluorescent neon (it's beyond any
printer gamut). Poly sublimation has the widest textile gamut, so it gets "almost glowing," just
not true fluo.

| Workaround | What | Caveat |
|---|---|---|
| **★ Fluorescent sublimation ink set** (add Fp + Fy channels) | Real: Roland Texart SBL3-FY, Epson Bright F6470H, Hanrun HD-NEON | **Confirm Formme's rig runs a fluo ink channel** `[confirm]`; fluo dye-sub fades faster (flag UV/wash) |
| Screen-printed neon over sublimation | Fluorescent plastisol at punch areas | Hand/flex-crack; harder for smooth gradients |

**Recommendation:** if Formme has fluo (Fp/Fy) inks → do the whole gradient in sublimation
(cleanest on poly). If not → print a near-neon approximation and spot-add screen-printed fluo
only where you need true pop. **Proof the gradient before the run.**

## 6. Name & number standards

Two regimes — **FIFA Equipment Regulations** (verified verbatim) and **teamwear norms** (amateur).

| Element | FIFA spec | Source |
|---|---|---|
| Back number — men's / women's | **25–35 cm / 20–35 cm**; stroke 3–5 cm | FIFA Equip. Reg. 6.4 |
| Front number (chest) | **10–15 cm** | 6.5 |
| Shorts number | **10–15 cm** | 6.6 |
| Back name | **5–7.5 cm**, ≥4 cm above number | 7.5 |
| Sleeve numbers | no FIFA spec — ~5–8 cm typical `[c]` | teamwear norm |

**Teamwear (amateur) norms:** back number adult 8–10″ / youth 6–10″; front 4–10″ / 3–8″; back
name 2.5–3″ adult, 1″ name→number gap.

**FIFA construction rules worth copying:** names/numbers **sewn or heat-affixed permanently — no
Velcro**; number fully visible when shirt tucked; breathing holes ≤2 mm; name letters same
colour as number, Latin characters; number must contrast + be legible at distance.

**Application methods:** sublimated (zero hand, must be pre-planned) · heat flock (premium retro
tactile) · HTV/vinyl (thin, sharp, cheap small runs) · sewn tackle twill (pro raised, most
durable, large only). *Hybrid "sublimated twill" = print onto laser-cut twill then sew = twill
durability + complex artwork.*

> For a **non-FIFA** league, confirm that league's equipment rules; FIFA cm ranges are the safe default.

## 7. Labels & legal

### 7.1 Woven vs tagless

**Recommendation: tagless heat-transfer care/size print at the neck** (comfort + sublimation-
friendly) **+ a small woven brand flag** (the common pro hybrid).

### 7.2 Legal labeling — Canada + US

| Requirement | 🇨🇦 Canada (Textile Labelling Act, Competition Bureau) | 🇺🇸 US (TFPIA 16 CFR 303; Care Rule 16 CFR 423, FTC) |
|---|---|---|
| Fibre content | Generic name of each fibre ≥5%, % by mass, in order of predominance | Same |
| Language | **Bilingual EN + FR** | English |
| Dealer identity | Name + full address **or a CA Identification Number** ($100 one-time) | Name **or an FTC RN** (optional) |
| Country of origin | Required | Required |
| Care instructions | **Voluntary** (but if given, must be accurate) | **Mandatory**, permanent, legible for the garment's life |

**Dual-market label (build to the stricter union):** bilingual EN/FR fibre content + % by
weight · dealer identity (a **CA number** covers Canada, name or **RN** covers US) · country of
origin · full **US-compliant care instructions** (also satisfies Canada) · **ASTM D5489 care
symbols** (the US-legal set; ISO/GINETEX symbols are *not* US-legal on their own) + French care
words for Canada's bilingual rule. A CA number / RN keeps the label compact. `[confirm implementation]`

**Neck label content (MADE ON):** brand · style no. · size · *"made on unceded xʷməθkʷəy̓əm,
Sḵwx̱wú7mesh, səlilwətaɬ territory."*

### 7.3 Hangtag = manifesto card

Recycled card (up to 100% PCW) / kraft / FSC stock; soy-veg inks; jute/paper string (no plastic
ties); no lamination (keeps it recyclable/compostable). Side A: the MADE ON statement. Side B:
the kit's receipts + QR to a DTES / land-back org.

## 8. Construction / stitching

| Stitch | Where on the kit |
|---|---|
| **Overlock (serger)** | Primary panel seaming — shoulder, side, sleeve/raglan seams; 5-thread safety on load-bearing side seams; internal seam finish on shorts |
| **Coverstitch** | Hems & openings — jersey bottom hem, sleeve cuffs, neckline finish, shorts leg hems, **waistband/elastic attachment** |
| **Flatlock** | Low-bulk skin-contact seams to reduce chafe — underarm, inner-thigh/crotch gusset |
| **Bartack** | Reinforce stress points — side-vent/split-hem ends, drawcord/waistband anchors, pocket corners. ~6–8 mm `[c]`; don't over-stiffen stretch fabric |

**Tonal thread** (match body colour) so seams read clean and the *garment* shows, not the
stitching — contrast thread only as a deliberate decorative choice.

## 10. Manufacturer pre-production checklist

The consolidated `[confirm]` items — hand this list to Formme before the 10-kit run.

1. **Run one strike-off on the actual blank** before all 10 — locks the real limits for engraving-line minimum (~1.5 mm), hem micro-type minimum (~0.3 mm stroke / 6–8 pt), and gradient/neon reproduction.
2. **Size block:** confirm all `[confirm]` POM rows (jersey shoulder/bicep/neck/hem; shorts waist-stretched/hip/thigh/rise/leg-opening/total-length) against Formme's actual block + a sample before bulk cut. The published rows (jersey chest/body-length/sleeve, shorts relaxed-waist/inseam, all body charts) are not flagged.
3. **Metallic gold (MO-03):** confirm Stahls CAD-CUT Metallic Gold press temp on heat-sensitive poly (cover sheet?); confirm CMYK for the old-gold fallback vs Formme's ICC profile.
4. **Gloss redaction bars (MO-01):** confirm silicone/gloss-DTF bonds to the *sublimated* surface and survives wash; keep bars on low-flex zones.
5. **Neon (MO-09):** confirm whether Formme's sublimation rig runs a fluorescent (Fp/Fy) ink channel → determines true-neon vs near-neon + spot screen.
6. **Recycled certs:** get the GRS/RCS chain-of-custody cert # + recycled % and OEKO-TEX cert # from the mill for the BOM line.
7. **Names/numbers:** if a non-FIFA league, confirm that league's equipment regs; else FIFA cm ranges default.
8. **Label:** one combined dual-market label (bilingual EN/FR fibre %, CA number + RN, country of origin, US-compliant care + ASTM D5489 symbols).
