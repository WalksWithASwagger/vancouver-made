## How to use these

For the protest kit design, the strongest transferable techniques are:

1. **Coded accessories** (01, 02) — load garment details with meaning without printing a slogan
2. **The artist's own platform** (03) — the schoolhouse wall as the medium
3. **Who owns this culture** (04, 05) — wear the authenticity question explicitly
4. **Sacred form → brand asset** (06) — Ilanaaq as cautionary tale and inspiration
5. **Body as protest surface** (07) — standard kit + defiant posture
6. **Perfect mimicry + inverted payload** (08) — reproduce sponsor/FIFA visual language exactly, then twist it
