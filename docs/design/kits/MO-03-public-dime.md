## Print method
Allover guilloché = dye-sublimation before cut-and-sew. Hem micro-type = fine
screen / high-density heat transfer; confirm min point size w/ Formme. Metallic gold:
confirm Formme can run it, else warm ochre.

## Why it wins
The number IS the kit: the most quotable object on the floor. Metallic banknote
engraving is a craft flex; the public-cost receipt is printed into the garment, not
captioned beside it.
