# Nardwuar FC — Graphic Elements (Rafiki / Nano Banana Pro)

`--style nardwuar -m pro -r 1K`, feeding curated moodboard plates as
`--reference-role style`. Palette + ethics (homage, no likeness) live in the style suffix.
