# Nardwuar FC — Mood Board (Rafiki / Nano Banana Pro)

Reference plates: tartan host-nation polish over riso-zine grit. Generate with
`--style nardwuar -m pro -r 1K`. Palette + ethics (homage, no likeness) live in the style
suffix; these prompts set subject + composition only. No human faces anywhere.

## 1. Tartan check, ghosted into fabric
**For:** All-over ghosted base texture, body colourway
**Aspect Ratio:** 4:5
**Prompt:**
> Extreme macro of a woven tartan check — tartan red crossed with tartan green and a thin tartan-yellow overcheck — ghosted faint as if printed into matte sportswear jersey fabric, fine sett detail, heritage textile precision, official home-kit gravity. Full-bleed.
