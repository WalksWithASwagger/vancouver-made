# Jersey Flats Prompts — NARDWUAR FC

**Goal:** Generate complete jersey flat mockups (front / back / side, technical
illustration style) for the full **home / away / third** family, ready for presentation
or iteration.

**Strategy:** Technical fashion-illustration prompts that respect the template and read
as a host-nation home kit from across the room, a walking archive up close.

**Ethos, not likeness:** No face, no portrait, no caricature — homage through objects only.

**MJ settings:** `--ar 3:4 --style raw` (portrait, fashion-design standard)

**Palette:** tartan red `#c8102e` · vinyl ink `#0a0a0a` · tartan green `#1d7a46` · tartan yellow `#e8c531`

## Iteration Strategy

**Round 1 (Prompts 1–3):** Lock the hero HOME kit — front, back, sleeve — in the tartan
colourway. This sets the core direction.

**Round 2 (Prompts 4–7):** Generate the AWAY (bone newsprint) and THIRD ("Unsanctioned
Press") family members once the home read is right.

**Round 3 (Prompts 8–9):** Detail close-ups (crest, nameplate/number) for the design-system
section of the deck.

**Round 4 (Prompt 10):** Full kit (jersey + shorts + socks) as the closing composition.

---

## Technical Notes

- **White background:** essential for clean extraction onto presentation materials.
- **No likeness:** review every generation — if a recognizable face appears, discard and
  re-prompt toward the objects (tam, records, mic stand). This is non-negotiable per the
  ethics note in `../../../../src/data/clubs.js`.
- **Receipt on the hem:** APEC-1997 citation (`AL-NW-001`). Cross-check the wording against
  `clubs.js` before generating — no stat drifts from source.
- **Register:** "technical flat-lay fashion illustration", "professional sports apparel",
  "ready for production" — avoid "photo-realistic".
