# Graphic Elements Prompts — HOGAN'S ALLEY FC

**Goal:** Standalone graphics to composite onto jersey templates — the kit-of-parts:
all-over patterns, the crest, the honour board (sponsor) marks, nameplate, number.

**Strategy:** `white background` in every prompt for clean masking/extraction.

**Discipline:** Original geometry only — **no kente / Ankara / Adinkra or any specific
sacred or cultural motif.** Afrofuturist and jazz-era languages, invented patterns.

**MJ settings:** `--ar 16:9 --style raw`

---

## Composition / Assembly
Layer order: base indigo → gold-weave all-over → star-map overlay (low opacity) → ghosted
grid (memory layer) → crest (left chest) → BLACK CULTURAL CENTRE sponsor bar (centre) →
nameplate + number (back) → hem microprint. **Colour-lock:** indigo `#1e1248`, gold
`#e8b04b`, violet `#5a2d9c`, bone `#ede6d8`. Keep gold for the marks; never let the weave
overpower the crest.
