# Mood Board Prompts — HOGAN'S ALLEY FC

**Goal:** Establish the visual language for "memorial + generative" — a gorgeous
Afrofuturist heritage kit that reads as celebration and as memory at once. Official
heritage-kit polish in service of a reclamation, not a souvenir.

**Aesthetic:** Cosmic gold + jazz-era warmth + the architecture of return. Afrofuturist
star-maps, brass-and-Deco jazz heritage, blueprint linework of the block coming home.

**Discipline:** **Original geometry only.** Evoke Afrofuturist and jazz-era visual
languages; **never reproduce kente, Ankara, Adinkra or any specific sacred/cultural
motif.** This kit amplifies a community — it does not borrow its sacred marks.

**MJ settings:** `--ar 4:5 --style raw` (portrait, documentary vibe, no artistic filter)

## Synthesis Notes
- **Dominant trio:** cosmic indigo + metallic gold + cosmic violet.
- **Texture language:** celestial polish + jazz-era warmth + blueprint precision.
- **Typography feel:** brass-Deco display + clean technical caps.
- **The duality to keep:** every frame should read as *celebration* and *memory* at once.
- **The line that must hold:** original geometry — no appropriated sacred motifs.
