# Jersey Flats Prompts: PUMP & DUMP FC

**Goal:** Generate complete jersey flat mockups (front and back, technical illustration style) ready for presentation or iteration.

**Strategy:** Use technical fashion illustration prompts that respect the template and allow for clean composition. Include all design elements as described in the submission brief.

**MJ settings:** `--ar 3:4 --style raw` (portrait/vertical, fashion design standard), `--niji` (optional, for cleaner technical rendering)

---

## Approach

Each prompt should generate a complete flat-lay technical illustration showing:
- Jersey silhouette (match the blank template proportions)
- All-over print pattern (candlestick charts or tower pattern)
- Crest (left chest)
- Sponsor bars (center and neck)
- Colorway (navy + teal/magenta accents)
- Any sleeve or trim details

## Iteration Strategy

**First Round (Prompts 1–3):**
Generate the three primary views (front, back, sleeve detail) with the flagship colorway and pattern. These establish the core design direction.

**Second Round (Prompts 4–5 + 6 if needed):**
If the first generation feels right, move to detail shots (7–9) for close-ups.
If the pattern or colorway needs adjustment, generate alternative colorway explorations (4–5) or try the hybrid pattern (6).

**Third Round (9–10):**
Once jersey locks, generate the full kit (shorts + socks) to show the complete submission vision.

---

## Technical Notes for Midjourney

- **`--niji` flag optional:** May help with cleaner technical rendering (Niji style is good for design mockups)
- **White background:** Essential for easy extraction and composition onto presentation materials
- **Aspect ratio 3:4:** Standard fashion illustration proportion; allows clean jersey rendering
- **"professional sportswear design" / "technical illustration" language:** Gets cleaner, more usable output than "photo-realistic" or "realistic"
- **Color specificity:** Reference hex codes in prompts or use descriptive color names ("midnight navy," "toxic teal," "stamp red")

---

## Presentation Use

Once jersey flats are locked:
1. **Use top 1–2 images** as hero visuals in the presentation deck (full front + back)
2. **Detail shots** (crest, sponsor bar, nameplate) as supporting images in "process" or "design system" section
3. **Full kit** as the final closing image before the pitch line
