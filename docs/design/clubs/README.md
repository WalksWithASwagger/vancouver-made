# ALLEY LEAGUE: the three flagship clubs

Three kits that pass as official FIFA World Cup 2026 host-city gear from a distance
and turn the brand back on itself up close, each asking *who benefits, who pays.*
Canonical data lives in `src/data/clubs.js`; these docs are the editorial / tech-pack
build-out. Voice and palette: `docs/design/brand-system.md` + `src/brand/tokens.js`.

set reads as one host-city kit drop rather than three loose ideas.

## The reveal mechanic
Every kit is built on the same two-distance trick: the engine of the whole
collection:
- **TV read (10 metres):** a premium, broadcast-ready official drop. Clean paneling,
  foil trim, the limited-edition gloss. It should pass on a highlight reel.
- **Street read (arm's length):** a protest poster. The sponsor board is a labour
  manifest / a press credential / an offering memorandum; the numbers, crest and
  hem all resolve into evidence.

If a beat doesn't survive *both* reads, it's not finished.

## Shared spoof system (the "World Cup, evil twin" kit)
Mirrors `clubs.js#sharedSpoof`. These elements are identical across all three so the
set hangs together as one counterfeit-official identity:
- **Host-city crest frame:** one shield outline on all three; only the inner art
  changes (orange marquee / record-flyer collage / candlestick-condo stack).
- **Faux tournament patch:** where a FIFA mark would sit: `UNOFFICIAL HOST CITY DROP`
  / `THIS KIT IS NOT LICENSED BY ANYONE`.
- **Host-city lockup**: `VANCOUVER 2026 — UNOFFICIAL`.
- **Trophy misuse**: the trophy silhouette is reused, recoded per club: neon door
  **marquee** (No.5), **mic-stand / vinyl spindle** (Nardwuar), **condo tower /
  bubble** (Pump & Dump).
- **Back-neck badge / campaign**: `NO GAME WITHOUT THE GROUND` on every kit.

## The rule (never reproduce, always evoke)
EVOKE the official system: the "26", host-city lockups, hospitality / credential /
sponsor-board language, the trophy, fan-zone wristbands, "city pride" third kits, but
**never reproduce actual FIFA marks.** Build a parallel, counterfeit-official identity
in our own voice. See the FIFA evocation rule at the top of `src/data/clubs.js`.

## Ethics, in one line
Punch **up** at FIFA, promoters, developers, capital and the bylaw. The workers, the
underground, and the public bagholders are the **home team, never the joke.** Every
claim on a garment carries its citation on the hem; anything flagged `confirm: true`
gets primary-source verification before it goes public. The owner is the final guard.
