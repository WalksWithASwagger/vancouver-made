# MADE ON — Kit Mockups (Canva)

Raster hero-kit mockups generated via the Canva MCP, 2026-06-20. PNGs in this folder.

## ⚠️ Known issue — REMOVE BEFORE PUBLISHING
Canva's generator added a **Nike swoosh** to each jersey render despite explicit
"no logos" prompts. It must be removed — both a trademark issue and a direct
contradiction of the MADE ON thesis (no borrowed brand imagery). Each design is
editable in Canva (links below): delete the swoosh, optionally drop in a plain
`MADE ON` maker dot. ~30 seconds per kit.

The MO-03 v1 also came out as a generic template poster ("really great site"
filler) and was replaced by the v2 single-jersey render below.

## Notes
- Each Canva `generate-design` call returns 4 candidates; only candidate 1 was
  rendered here. Open the edit link to swap to an alternate or refine.
- The in-app **SVG kit flats** (`src/components/KitFlat.jsx`) remain the spec-accurate,
  logo-free mockups; these Canva renders are the photoreal companions.
- Export download links from Canva are temporary (expire in hours); the PNGs here
  are the committed copies.
