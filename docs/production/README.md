# Production jersey program

This directory contains the clean-sheet production program for the five-jersey prize and the intended first community run. The earlier Nardwuar submission remains historical reference only. No identity, crest, tartan, slogan, artwork, or panel graphic from that submission is reused here.

## Current lock

- Style: `BCAI-01`
- Name: `BOTH / AND Community Match Kit`
- Garments: short-sleeve jersey and matching shorts
- Decoration: two-colour screen print plus a small two-colour embroidery
- Manufacturing intent: premium stock dark body, no all-over sublimation, no names or numbers
- Factory deadline: Sunday, July 26, 2026

The factory-facing specification is generated from [`both-and/spec.json`](both-and/spec.json). Run:

```sh
/Users/kk/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 scripts/build-production-techpack.py
```

Generated deliverables land in `output/pdf/` and `output/production/BCAI-01/`.

## Production gates

The design direction and artwork are locked. The factory must return its size chart, material swatches, lab dips, ink drawdowns, embroidery sew-out, print strike-off, graded placement map, and a pre-production sample before bulk manufacture. Those are technical approvals, not invitations to redesign the concept.
